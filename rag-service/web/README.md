# RAG Web Interface

Modern web interface for managing RAG Knowledge Base.

## Features

- 📊 **Dashboard** - View system status and statistics
- 📤 **Document Upload** - Upload and manage documents
- 💬 **Test Chat** - Test RAG responses in real-time
- 🎨 **Modern UI** - Beautiful, responsive design with TailwindCSS

## Installation

```bash
cd web
npm install
```

## Development

```bash
npm run dev
```

Open http://localhost:3000

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18
- Vite
- TailwindCSS
- Lucide Icons
- Axios
